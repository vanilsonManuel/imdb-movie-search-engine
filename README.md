# 🎬 IMDb Movies Search Engine

Aplicação interativa desenvolvida em Python para pesquisa inteligente de filmes do IMDb utilizando correspondência aproximada de texto (Fuzzy Matching).

O projeto foi desenvolvido como Projeto Final do curso de Programação Python e Análise de Dados da Master D.

---

# 🚀 Funcionalidades

✅ Pesquisa inteligente de filmes  
✅ Correspondência aproximada com RapidFuzz  
✅ Interface interativa com Streamlit  
✅ Tratamento e limpeza de dados com Pandas  
✅ Visualização de informações dos filmes  
✅ Estrutura modular e organizada  

---

# 🛠️ Tecnologias Utilizadas

- Python
- Pandas
- Streamlit
- RapidFuzz

# ⚙️ Instalação

Instalar as bibliotecas necessárias:

```bash
pip install -r requirements.txt
```

---

# ▶️ Executar o Projeto

```bash
streamlit run app.py
```

---

# 🔎 Exemplo de Pesquisa

O utilizador pode pesquisar filmes mesmo com erros ortográficos:

```text
Hary Ptter
```

A aplicação retorna filmes semelhantes utilizando fuzzy matching.
